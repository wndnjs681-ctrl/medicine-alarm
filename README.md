# 복약노트 (Medicine Alarm)

한국어 약 복용 관리 웹앱입니다. React와 Vite로 실행하며 별도 서버, 데이터베이스, API 키는 필요하지 않습니다.

## 기능

- 약 이름, 용량, 하루 여러 복용 시간, 요일, 메모 등록 및 수정
- 날짜별 복용 일정과 완료/취소 기록
- 약 삭제 후에도 완료 기록 보존
- 브라우저 복용 알림과 중복 알림 방지
- JSON 형식 데이터 내보내기
- 데스크톱과 모바일 화면

## 실행

Node.js 24 LTS와 npm을 사용합니다. 이 저장소의 기존 체크아웃에서 실행하세요.

```bash
npm ci --cache /tmp/medicine-alarm-npm-cache --no-audit --no-fund
npm run dev -- --port 5173 --strictPort
```

홈 디렉터리를 쓸 수 없는 클라우드 환경에서도 위 캐시 경로로 설치할 수 있습니다. 포트가 사용 중이면 다른 포트를 지정하세요. 외부에 노출할 때는 신뢰할 수 있는 환경의 접근 제어를 사용하세요.

## 검증

```bash
npm test
npm run build
npm run test:e2e
```

단위 테스트는 일정, 날짜, 복용 기록, 알림 시점, 저장 데이터 검증을 검사합니다. Playwright는 데스크톱과 모바일에서 등록·수정·삭제, 기록 유지, 내보내기, 알림 호출/중복 방지, 화면 크기를 검사합니다. 알림 테스트는 브라우저 Notification API를 대체해 호출을 확인하며 실제 운영체제 알림 전달을 보장하지 않습니다.

클라우드 환경에서는 기본 제공 `/usr/bin/chromium`을 자동 사용합니다. 다른 Chromium은 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 지정할 수 있습니다. Chromium이 없는 일반 개발 환경에서는 먼저 `npx playwright install chromium`을 실행하세요. 브라우저 테스트는 임시 개발 서버를 4173 포트에서 실행하고 종료합니다.

## 저장 및 알림 조건

- 약과 기록은 현재 브라우저의 `localStorage`에만 저장됩니다. 서버 전송과 기기 간 동기화는 하지 않습니다. 브라우저 데이터를 지우기 전에 데이터를 내보내세요. 내보낸 JSON을 가져오는 기능은 아직 없습니다.
- 여러 탭에서 동시에 편집하면 마지막 저장으로 덮어쓸 수 있으므로 한 탭에서 사용하세요.
- 알림은 HTTPS 또는 localhost의 지원 브라우저에서 알림 권한을 허용하고 이 페이지를 열어 두어야 작동합니다.
- 앱은 약 15초 간격으로 복용 시간을 확인합니다. 잠들거나 닫힌 브라우저에서는 알림을 보장하지 않으며, 다시 열었을 때 15분 이내의 미복용 일정만 알립니다. 모바일 브라우저별로 데스크톱 Notification API 지원이 다릅니다.
- 처음 등록한 날짜부터 일정이 생성됩니다. 약 정보를 수정하면 일정에 반영되며 이미 완료한 기록의 이름과 용량은 보존됩니다.
- 복용량과 복용 시간은 의료진의 안내를 따르세요. 이 앱은 처방을 판단하지 않습니다.

## 클라우드 환경

설치 명령과 시작 지침은 환경 설정의 `install_script`와 `start_skill`에 저장됩니다. 설정 초안을 저장해도 환경 게시나 GitHub 업로드가 자동 실행되지는 않습니다. 게시된 환경 스냅샷에서 파일과 의존성을 복원할 수 있으나 개발 서버는 작업마다 다시 시작해야 합니다.

각 클라우드 작업은 이미 격리된 환경입니다. 기존 `/workspace/medicine-alarm` 체크아웃을 사용하고, 사용자가 요청하지 않는 한 별도 Git worktree를 만들지 마세요.
