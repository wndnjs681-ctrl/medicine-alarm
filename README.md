# 복약노트 (Medicine Alarm)

한국어 약 복용 관리 웹앱입니다. React와 Vite로 실행하며 별도 서버, 데이터베이스, API 키는 필요하지 않습니다.

## 기능

- 약 이름, 용량, 하루 여러 복용 시간, 요일, 메모 등록 및 수정
- 날짜별 복용 일정과 완료/취소 기록
- 약 삭제 후에도 완료 기록 보존
- 브라우저 복용 알림과 중복 알림 방지
- JSON 형식 데이터 내보내기
- 데스크톱과 모바일 화면
- Android 홈 화면 위젯: 오늘 진행률, 다음 미복용 약, 앱을 열지 않고 복용 완료

## 실행

Node.js 24 LTS와 npm을 사용합니다. 이 저장소의 기존 체크아웃에서 실행하세요.

```bash
npm ci --cache /tmp/medicine-alarm-npm-cache --no-audit --no-fund
npm run dev -- --port 5173 --strictPort
```

홈 디렉터리를 쓸 수 없는 클라우드 환경에서도 위 캐시 경로로 설치할 수 있습니다. 포트가 사용 중이면 다른 포트를 지정하세요. 외부에 노출할 때는 신뢰할 수 있는 환경의 접근 제어를 사용하세요.

## 검증

```bash
npm test
npm run build
npm run test:e2e
```

단위 테스트는 일정, 날짜, 복용 기록, 알림 시점, 저장 데이터 검증을 검사합니다. Playwright는 데스크톱과 모바일에서 등록·수정·삭제, 기록 유지, 내보내기·가져오기, 알림 호출/중복 방지, 화면 크기를 검사합니다. 알림 테스트는 브라우저 Notification API를 대체해 호출을 확인하며 실제 운영체제 알림 전달을 보장하지 않습니다.

클라우드 환경에서는 기본 제공 `/usr/bin/chromium`을 자동 사용합니다. 다른 Chromium은 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 지정할 수 있습니다. Chromium이 없는 일반 개발 환경에서는 먼저 `npx playwright install chromium`을 실행하세요. 브라우저 테스트는 임시 개발 서버를 4173 포트에서 실행하고 종료합니다.

## 저장 및 알림 조건

- 웹의 약과 기록은 현재 브라우저의 `localStorage`에만 저장됩니다. 서버 전송과 기기 간 동기화는 하지 않습니다. 브라우저 데이터를 지우기 전에 데이터를 내보내세요. 설정에서 복약노트의 JSON을 가져올 수 있으며, 확인 후 현재 목록과 기록을 교체합니다.
- 여러 탭에서 동시에 편집하면 마지막 저장으로 덮어쓸 수 있으므로 한 탭에서 사용하세요.
- 알림은 HTTPS 또는 localhost의 지원 브라우저에서 알림 권한을 허용하고 이 페이지를 열어 두어야 작동합니다.
- 앱은 약 15초 간격으로 복용 시간을 확인합니다. 잠들거나 닫힌 브라우저에서는 알림을 보장하지 않으며, 다시 열었을 때 15분 이내의 미복용 일정만 알립니다. 모바일 브라우저별로 데스크톱 Notification API 지원이 다릅니다.
- 처음 등록한 날짜부터 일정이 생성됩니다. 약 정보를 수정하면 일정에 반영되며 이미 완료한 기록의 이름과 용량은 보존됩니다.
- 복용량과 복용 시간은 의료진의 안내를 따르세요. 이 앱은 처방을 판단하지 않습니다.

## Android 홈 화면 위젯

Android 8.0 이상에서 사용하는 네이티브 위젯입니다. Capacitor로 기존 웹앱을 Android 앱에 포함하고, 같은 앱의 저장소를 위젯과 공유합니다. 인터넷 연결 없이 일정 확인과 복용 완료를 기록할 수 있습니다.

설치용 개발 APK는 `android/app/build/outputs/apk/debug/app-debug.apk`에서 생성됩니다. 휴대폰에 설치한 뒤 앱을 한 번 열고 약을 등록하세요. 앱 상단의 위젯 아이콘 또는 설정의 **위젯 추가**로 홈 화면에 추가할 수 있습니다. 또는 홈 화면을 길게 누르고 위젯 목록에서 **복약노트**를 선택하세요.

- 기본 4×2 위젯이며 크기를 조절할 수 있습니다. 미복용 시간이 지난 약을 먼저 표시하고, 없으면 다음 예정 약을 표시합니다.
- 위젯의 **복용 완료**는 표시된 약 한 번의 복용을 기록합니다. 취소는 앱에서 할 수 있습니다. 중복 탭으로 기록이 중복되지 않으며, 날짜가 지난 버튼은 새 날짜에 잘못 기록하지 않습니다.
- 앱에서 변경하거나 위젯에서 완료하면 모든 위젯을 갱신합니다. 날짜·시간·시간대 변경 및 Android의 약 30분 주기 갱신에도 반영합니다. OS의 절전 정책으로 자동 갱신이 늦어질 수 있습니다.
- 앱이 오래된 데이터를 저장하려 하면 위젯의 최신 기록을 보존하고 다시 시도하도록 알립니다.
- Android 앱 데이터와 기존 Chrome 브라우저 데이터는 서로 다른 저장소입니다. 기존 기록은 웹앱에서 JSON으로 내보내고 Android 앱 설정에서 가져오세요. Android에서는 시스템 파일 선택기로 내보냅니다. 앱 삭제 시 앱과 위젯의 기록도 사라집니다.
- 위젯 자체는 예약 알림을 발송하지 않습니다. Android WebView의 웹 알림 지원은 제한적이며, 네이티브 예약 알림은 별도 기능입니다.
- 이 APK는 개발용 디버그 서명입니다. Play Store 게시용 릴리스 서명과 스토어 배포는 포함하지 않습니다.

### Android 빌드

일반 개발 환경에서는 JDK 21, Android SDK 36 및 Build Tools 35.0.0/36.0.0을 설치하고 `ANDROID_HOME`을 설정하세요.

```bash
npm ci --cache /tmp/medicine-alarm-npm-cache --no-audit --no-fund
npm run android:build
```

이 클라우드 환경에서는 설치 스크립트가 서명·체크섬 및 TLS 검증을 유지하면서 `/workspace/.cache/medicine-alarm-android`에 도구를 준비합니다. 시스템 프록시와 세션 CA를 사용하며 홈 디렉터리를 변경하지 않습니다.

```bash
bash scripts/setup-cloud-android.sh
source scripts/cloud-android-env.sh
npm run android:build
```

`android:build`는 웹 빌드 및 Capacitor 동기화 후 APK 생성, Robolectric 위젯 테스트, Android lint를 실행합니다. Robolectric은 복용 완료, 날짜·요일 계산, 중복 방지, 오래된 앱 쓰기 거부, 기록 유지, 실제 RemoteViews 화면 구성을 검사합니다. 클라우드 테스트는 실제 갤럭시 런처에서 설치·핀 고정·파일 선택기 동작을 직접 검사하는 것을 대체하지 않습니다.

## 클라우드 환경

설치 명령과 시작 지침은 환경 설정의 `install_script`와 `start_skill`에 저장됩니다. 설정 초안을 저장해도 환경 게시나 GitHub 업로드가 자동 실행되지는 않습니다. 게시된 환경 스냅샷에서 파일과 의존성을 복원할 수 있으나 개발 서버는 작업마다 다시 시작해야 합니다.

각 클라우드 작업은 이미 격리된 환경입니다. 기존 `/workspace/medicine-alarm` 체크아웃을 사용하고, 사용자가 요청하지 않는 한 별도 Git worktree를 만들지 마세요.
